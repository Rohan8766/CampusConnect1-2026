# 🎓 CampusConnect 2026

## Student Event Registration Portal

CampusConnect 2026 is a modern web-based Student Event Registration Portal developed using PHP, MariaDB, HTML, CSS and Apache.

## 🚀 Features

- Student Registration
- Secure Login System
- Student Dashboard
- Event Registration
- Password Hashing
- MariaDB Database
- AWS EC2 Deployment
- Responsive Modern UI

## 🛠️ Technologies Used

- PHP
- HTML5
- CSS3
- MariaDB
- Apache
- Amazon Linux
- AWS EC2
- Git & GitHub
